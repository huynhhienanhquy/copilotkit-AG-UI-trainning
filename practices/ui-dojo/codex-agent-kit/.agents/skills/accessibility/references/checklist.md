# accessibility checklist

- [ ] Target WCAG level defined (A, AA, or AAA)
- [ ] Semantic HTML: headings hierarchy, landmarks, lists, tables
- [ ] All interactive elements keyboard reachable
- [ ] Logical tab order, no keyboard traps
- [ ] Visible focus indicator on all interactive elements
- [ ] Focus returned after modal/dialog close
- [ ] Labels associated with form inputs
- [ ] Error messages linked to inputs via aria-describedby
- [ ] Required fields indicated visually and programmatically
- [ ] Alt text for informative images, empty alt for decorative
- [ ] ARIA roles used only when native HTML semantics insufficient
- [ ] Color contrast ratios meet WCAG minimums (4.5:1 normal, 3:1 large)
- [ ] Color is not the sole means of conveying information
- [ ] Live regions used for dynamic content updates
- [ ] Tested with screen reader (VoiceOver, NVDA, or similar)
- [ ] Findings documented with severity and remediation
